# Configuration Files

## simulation.yaml
Main configuration file for the IoT simulator.
All user-settable parameters are documented inline.

## node_950_C.csv (not included)
Real 4G/5G upload speed measurements from the NorNet Edge (NNE) platform,
collected across Norway (Nov 2023 - Feb 2024).

This file is **not included** in the repository because it is proprietary
research data. See `node_950_C.csv.example` for the expected format.

To run the simulator you need to either:
1. Obtain the NNE dataset and place it here
2. Generate a synthetic CSV with the same format using the example above

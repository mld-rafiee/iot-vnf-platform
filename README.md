# IoT VNF Testbed

A full-stack IoT data engineering testbed built on Kubernetes,
using Virtual Network Functions (VNFs) as the processing layer.

## Infrastructure

- **Cloud:** NREC (Norwegian Research and Education Cloud)
- **Orchestration:** Kubernetes
- **Nodes:** 9 (1 master, 6 VNF workers, 1 tool node, 1 edge node)
